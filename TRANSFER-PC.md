# Запуск игры на ПК

Этот архив содержит веб-игру Slendytubbies II Web 0.2: одиночный режим,
кооператив на 2–4 игроков, исходный код сервера и готовую папку `dist/`.
Unity, Python, ключи API и повторное извлечение ресурсов не нужны.

## Быстрый запуск

1. Установите Node.js версии **22.12 или новее** с официального сайта Node.js.
2. Распакуйте архив и откройте терминал в папке с `package.json`.
3. Выполните:

```sh
npm ci --omit=dev
npm start
```

Оставьте терминал запущенным. Откройте:

- Игра: `http://127.0.0.1:4175/`
- Проверка сервера: `http://127.0.0.1:4175/api/health` — версия должна быть `0.2.0`.
- Другие устройства в одной Wi-Fi сети: `http://<локальный-IP-ПК>:4175/`.

В этом переносимом архиве актуальная готовая игра называется **`dist/`**.
Не задавайте `GAME_DIST=dist-next`: это имя использовалось на телефоне во время
обновления. Если в окружении есть старый `GAME_DIST`, удалите эту переменную
или установите её в `dist`. Сборка Vite для первого запуска не требуется.

Если для локальной сети требуется правило брандмауэра, разрешите TCP 4175 только
в доверенной частной сети. Не отключайте брандмауэр целиком и не завершайте чужой
процесс, если порт оказался занят.

## Публичная ссылка с ПК

1. Запустите сервер игры, как описано выше.
2. Установите **официальный cloudflared для ОС и архитектуры ПК**. Linux ARM64
   файл из инструкций для телефона не подходит для Windows/x64.
3. Во втором терминале выполните:

```sh
cloudflared tunnel --url http://127.0.0.1:4175 --http-host-header localhost:4175
```

4. Сохраните новый напечатанный HTTPS-адрес `https://....trycloudflare.com`.
   Адрес туннеля с телефона перенести нельзя; каждый новый Quick Tunnel получает
   другой адрес. Запущенный туннель оставьте работать.
5. Остановите **только сервер игры на ПК** в первом терминале. Задайте
   `PUBLIC_ORIGIN` равным новому HTTPS-адресу, без завершающего `/`, и запустите
   сервер игры снова. Эта переменная нужна для кооперативного WebSocket.

PowerShell:

```powershell
$env:PUBLIC_ORIGIN = 'https://НОВЫЙ-АДРЕС.trycloudflare.com'
npm start
```

Linux/macOS:

```sh
PUBLIC_ORIGIN=https://НОВЫЙ-АДРЕС.trycloudflare.com npm start
```

Не копируйте вымышленные адреса из этих примеров: используйте адрес,
который действительно напечатал ваш cloudflared.

Проверьте страницу, `/api/health` и создание комнаты по новой публичной ссылке.
Одиночные посетители играют независимо; им не требуется одна Wi-Fi сеть.
Сервер телефона не нужно останавливать для настройки ПК. Не останавливайте его
без отдельного подтверждения владельца.

Ссылка временная: нужны работающие ПК, сервер игры, cloudflared и Интернет.
Для постоянного адреса понадобится подходящий хостинг или собственный домен
с настроенным постоянным туннелем. Права на оригинальные игровые ресурсы
описаны в `README.md`.
